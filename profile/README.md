# Creditoscópio

**Os juros do crédito, vistos por inteiro.**

Plataforma independente de inteligência de crédito para o consumidor, construída sobre dados abertos do Banco Central. Quanto custa de fato uma modalidade? Como a taxa de uma instituição se compara ao mercado e como evoluiu? Quanto uma dívida cresce a determinada taxa?

## Princípios

- Só fonte oficial (Banco Central), com período e fonte ao lado de cada número.
- Sem dado, o site diz "sem dado no período". Nunca zero.
- Sem ranking de "melhores" e sem "melhor/pior": uma taxa maior ou menor não diz, por si só, que uma instituição é melhor ou pior.
- A taxa publicada é a média das operações da instituição na janela, não a oferta que você receberia nem o CET.

O Creditoscópio não é o Banco Central, não vende crédito, não intermedeia contratação e não recomenda instituições.
